# Stream clips · нарезки стримов

Локальный веб-инструмент: Twitch VOD (или файл) → транскрипция → отбор моментов → вертикальные ролики 9:16 для TikTok / Shorts.

Распознавание речи идёт **локально** (Whisper). Отдельный LLM-ключ нужен лишь чтобы лучше ранжировать моменты; без ключа пайплайн работает на эвристике (голос + словарь эмоций).

## Стек

- Python / FastAPI — очередь джобов
- `yt-dlp` — скачивание VOD
- Whisper (`mlx-whisper`, иначе `faster-whisper`) — транскрипция
- энергия RMS дорожки + LLM — кандидаты в короткие ролики
- FFmpeg — вёрстка 9:16, субтитры, водяной знак, конечная карточка
- Vite / React — ревью галочками, затем рендер

## Запуск

```bash
chmod +x scripts/dev.sh
./scripts/dev.sh
```

UI: [http://127.0.0.1:5260](http://127.0.0.1:5260)  
API: [http://127.0.0.1:8741/api/health](http://127.0.0.1:8741/api/health)

Скопируй `.env.example` в `.env`. Можно добавить `OPENAI_API_KEY` (подойдёт Groq / любой OpenAI-compatible `OPENAI_BASE_URL`) и `WATERMARK=twitch.tv/ник`.

## Как пользоваться

1. Вставь ссылку `https://www.twitch.tv/videos/...` или загрузи mkv/mp4.
2. Укажи угол камеры в OBS и водяной знак канала.
3. Дождись транскрипции. `large-v3` на M1 Pro для 3 часов — ориентир 40–90 минут.
4. Отметь моменты (по умолчанию топ-5).
5. «Смонтировать» → файлы в `data/jobs/<id>/clips/` плюс `meta.json` с хуком, описанием и хештегами.

В git не попадают `.env`, `data/`, модели, видео и виртуальное окружение — см. `.gitignore`.
